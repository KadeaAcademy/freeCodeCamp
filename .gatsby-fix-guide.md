# Guide de résolution permanente - Erreur ECONNRESET avec yoga-layout-prebuilt

## 🔧 Solution automatique implémentée

Un script de pré-vérification a été ajouté qui s'exécute automatiquement avant `npm run develop`. Ce script :

1. ✅ Nettoie automatiquement les caches Gatsby
2. ✅ Vérifie et répare yoga-layout-prebuilt si nécessaire
3. ✅ Tue les processus Gatsby existants qui pourraient causer des conflits

## 📝 Modifications apportées

### 1. Script automatique

- **Fichier** : `client/scripts/pre-develop-check.js`
- **Exécution** : Automatique avant chaque `npm run develop`

### 2. Configuration optimisée

- **Mémoire** : Augmentée à 7168MB
- **Workers** : Limité à 1 CPU (GATSBY_CPU_COUNT=1) pour éviter les conflits IPC
- **Options Node** : `--no-deprecation` ajouté

## 🚀 Utilisation

Lancez simplement :

```bash
npm run develop
```

Le script de vérification s'exécutera automatiquement avant le démarrage de Gatsby.

## 🔄 Si le problème persiste

### Solution rapide

```bash
cd client
npm run clean
npm run predevelop:check
npm run develop
```

### Solution complète

```bash
cd client
rm -rf node_modules/.cache .cache
npm rebuild yoga-layout-prebuilt
npm run develop
```

### Solution radicale (si rien ne fonctionne)

```bash
cd client
rm -rf node_modules .cache
npm install
npm rebuild yoga-layout-prebuilt
npm run develop
```

## 📌 Causes connues du problème

1. **Communication IPC** : Trop de workers Gatsby en parallèle
2. **Modules natifs** : yoga-layout-prebuilt mal construit
3. **Cache corrompu** : Fichiers de cache Gatsby corrompus
4. **Processus zombies** : Anciens processus Gatsby qui tournent encore

## ✅ Prévention

Le script `pre-develop-check.js` prévient automatiquement ces problèmes en :

- Nettoyant les caches avant chaque démarrage
- Vérifiant l'intégrité de yoga-layout-prebuilt
- Tuant les processus existants qui pourraient causer des conflits

## 🔍 Vérification manuelle

Pour exécuter uniquement le script de vérification :

```bash
cd client
npm run predevelop:check
```
